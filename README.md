Sistema de Gestión de Productos con ORM

Descripción


Proyecto académico desarrollado en Java utilizando Apache NetBeans, Hibernate, JPA y PostgreSQL. Su objetivo es aplicar el mapeo objeto-relacional (ORM) para conectar una aplicación Java con una base de datos.

Funcionalidades

Registrar productos.

Consultar productos almacenados.

Actualizar información de productos.

Eliminar productos.

Tecnologías utilizadas

Java: lenguaje de programación.

Apache NetBeans: entorno de desarrollo.

Hibernate y JPA: persistencia y mapeo objeto-relacional.

PostgreSQL: sistema de gestión de bases de datos.

Maven: gestión de dependencias y construcción del proyecto.

Ejecución

Clonar o descargar el repositorio.

Configurar la conexión a PostgreSQL en persistence.xml.

Abrir el proyecto en Apache NetBeans.

Ejecutar el proyecto para utilizar la interfaz gráfica.
